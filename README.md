# STAN.dard CV App

Die **STAN.dard CV App** ist eine moderne, einseitige SwiftUI-Anwendung, die professionelle Lebensläufe elegant und platzsparend visualisiert. Der Fokus liegt auf einem klaren UI-Layout, dynamischen Inhalten und subtilen Animationen für ein überzeugendes Nutzererlebnis – optimiert für iPhone-Displays.

## Features
- Header mit rundem Profilbild, Name und Kontaktinformationen  
- Klappbare Sektionen für **Über mich** und **Berufserfahrung**  
- Einheitlicher 3D-Look durch Schatten und Tiefeneffekte  
- Animierte Icons (GitHub, Figma, Swift, Kotlin)  
- Berufserfahrung mit **Timeline-Animation**  
- Intro-Animation beim App-Start  
- **Parallax-Effekte** im Header für mehr Dynamik  
- Responsives Layout, optimiert für kleinere Geräte (z. B. iPhone 13 mini)

## Technologien
- SwiftUI (Single-View Architektur)  
- Animationen mit `withAnimation` und `matchedGeometryEffect`  
- `GeometryReader` für Parallax-Effekte  
- Eigene Views und wiederverwendbare Komponenten  
- Dark-Mode-Unterstützung

## Ziel der App
Eine kompakte, ästhetische Lösung, um den eigenen Lebenslauf digital zu präsentieren – interaktiv, strukturiert und mobil optimiert. Ideal für Bewerbungen, Portfolio-Links oder Präsentationen.
